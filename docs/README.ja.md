# my-traffic-stats-view

GitHub トラフィック分析ダッシュボード

## 📊 ダッシュボードを表示

👉 **[ダッシュボードを開く](https://ynoda714.github.io/my-traffic-stats-view/)**

このダッシュボードは、ynoda714 が管理する GitHub リポジトリのトラフィック統計（ビュー数、クローン数）を毎日自動集計して表示します。

### 表示対象リポジトリ
- [AnyNMR-matlab](https://github.com/ynoda714/AnyNMR-matlab)
- [AnyResearch-matlab](https://github.com/ynoda714/AnyResearch-matlab)
- [EasyMolKit-matlab](https://github.com/ynoda714/EasyMolKit-matlab)

### 更新頻度
毎日 00:30 JST（UTC 15:30）に自動更新

---

### 📈 ダッシュボードについて

ダッシュボードには以下の情報が表示されます：

1. **サマリーテーブル（Cumulative Totals）**
   - 各リポジトリの累計ビュー数とクローン数

2. **時系列グラフ（Views / Clones — All Repositories）**
   - 全リポジトリ統合の日別トラフィック推移

3. **リポジトリ別詳細グラフ（Per Repository）**
   - 各リポジトリの個別トラフィック詳細

### 🔧 技術情報

- **表示エンジン**: Vega-Lite
- **公開方式**: GitHub Pages
- **データ源**: [my-traffic-stats](https://github.com/ynoda714/my-traffic-stats)
- **更新タイミング**: 毎日 UTC 15:30（JST 00:30）
